# 旅数刷题室 · 旅游数字化产品设计与营销

一个可直接上传到 GitHub Pages 的静态刷题网页，包含你提供的公开题库全部 500 道题与标准答案。模拟练习已按你提供的比赛规则设置为 **30 分钟、90 题、满分 100 分**。无需安装依赖，无需后端、数据库或 API 密钥。

## 最快部署方法

1. 在 GitHub 新建一个 **Public（公开）** 仓库，名称可用 `tourism-practice`。
2. **先解压此压缩包**，进入解压后的文件夹，将 `index.html`、整个 `assets` 文件夹、`README.md`、`.nojekyll` 等文件一起上传到仓库根目录并提交。不要只上传压缩包，也不要只上传 `index.html`。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment → Source** 选择 **Deploy from a branch**。
5. 将分支设为 **main**，文件夹设为 **/(root)**，点击 **Save**。
6. 等待 GitHub 完成发布，回到 Pages 页面，点击其显示的站点地址。

项目站点地址的格式通常为 `https://你的用户名.github.io/仓库名/`。请以 GitHub Pages 设置页面实际显示的地址为准。

最重要的一点：**在 GitHub 仓库首页能直接看见 index.html，同时能看见 assets 文件夹**。如果外面又套了一层目录，请把这层目录里的文件上传到根目录。

GitHub 官方发布说明：
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 不部署，先在电脑上使用

解压后双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开即可。所有脚本、样式、题库和 PDF 都放在本地，不依赖外部字体、图片服务或 CDN。手机建议在 GitHub Pages 部署后访问网页链接。

本地打开与在线站点的进度可能相互独立。如需转移，请使用进度导出与导入功能。

## 已包含的功能

- **完整题库**：单选 150 道、多选 150 道、判断 200 道。
- **顺序练习**：保留原题顺序，按题型切换，支持只练未提交过的题。
- **随机刷题**：一次生成无重复的随机顺序，可重新洗牌。
- **背题模式**：直接显示标准答案，不计入作答与正确率。
- **错题本**：提交错误答案时自动收录；重练答对后自动移出。
- **收藏**：随时标记需要复习的重点题。
- **比赛模拟**：固定 30 分钟，随机抽取 40 道判断、30 道单选、20 道多选，按题型分值计分，满分 100 分；交卷后查看分题型报告、回顾单题、重练错题和未答题。
- **题库检索**：搜索题干、选项和题型内原题号。
- **答题卡**：直接点击跳题，按状态区分已答对、已答错、已看答案、待提交和未答。
- **本地进度**：自动保存练习位置、草稿、错题、收藏和模拟状态。
- **进度备份**：导出 JSON、导入 JSON；导入替换当前记录，不进行合并。
- **原题追溯**：反馈区域保留原题号与 PDF 页码，可点击打开原 PDF。
- **移动端布局**：手机底部导航、可放大字号；电脑支持键盘操作。

## 怎样使用

### 日常练习

选择一个或多个选项后，点击「提交答案」。查看结果后点击「下一题」。多选题必须自己选完再提交。

- 单选与判断题每次只选一个答案。
- 多选题答案集合必须完全一致；漏选、多选、错选都判错。
- 「暂时不会，查看答案」只展示答案，不记录作答。
- 「背题模式」同样不计入已练题目和正确率。
- 同一轮的同一道题只在提交时记一次；点击「再答一次」后可新增一次作答记录。
- 「重新练这一组」或「重新洗牌」只重置本轮，不清空累计记录。
- 错题和收藏的本轮题目是进入时的快照，练习中保持顺序稳定。要载入最新题目，点击「更新本轮题目」。

电脑快捷键：`A–D` 或 `1–4` 选项，`←` / `→` 切换题目；判断题用 `A / 1` 选正确、`B / 2` 选错误。焦点不在按钮或输入框时，`Enter` 可提交或进入下一题。

### 模拟练习：比赛赛制

固定 **30 分钟**，共 **90 题**，满分 **100 分**，按你提供的比赛规则组卷：

| 题型 | 题量 | 每题分值 | 本项满分 |
| --- | --- | --- | --- |
| 判断题 | 40 题 | 1 分 | 40 分 |
| 单选题 | 30 题 | 1 分 | 30 分 |
| 多选题 | 20 题 | 1.5 分 | 30 分 |
| 合计 | 90 题 | — | 100 分 |

- 每轮从各题型的完整题库中随机抽取，卷内不重复。不同轮次可能抽到相同题目。
- 按判断、单选、多选的顺序出题，对应本轮第 1–40、41–70、71–90 题，各题型内部随机排序。
- 点击「开始 30 分钟模拟」即开始计时，不能自改时长、题型或题量。
- 总分直接累加各题得分，完整保留 0.5 分。例如全对为 100 分，仅错一道多选题为 98.5 分。
- 多选题沿用当前网页的严格判分方式：全部选对才得 1.5 分；漏选、多选、错选均为 0 分。你提供的规则尚未说明部分得分方式，因此未额外设置少选给分。
- 未答题为 0 分，并加入错题本；不计入累计作答次数。
- 作答过程中不显示正确答案，交卷后统一评分。
- 成绩报告分别显示判断、单选、多选的答对数量与得分；逐题回顾显示本题得分。
- 计时按实际截止时间计算。切换页面、关闭网页或刷新都不会暂停计时。
- 满 30 分钟自动交卷；如果到时网页已关闭，会在下次打开时自动结算。

### 从上一版更新

将本压缩包解压后的文件覆盖上传到原 GitHub 仓库，保持原文件名和目录结构。发布完成后刷新网页；如仍显示旧版界面，可强制刷新。

已有练习进度、错题、收藏和备份保持兼容。更新前已开始的自选模拟可以继续，并明确标注为「旧版自选模拟」，按当时规则结算；旧模拟报告保持原得分。之后新开模拟均采用 30 分钟、90 题赛制。

### 进度与备份

自动保存采用浏览器 `localStorage`。每位使用者的记录只保存在自己的当前设备和浏览器中，不会发送到服务器，也不会自动跨设备同步。多人在同一浏览器中使用会共用记录。

换设备、换浏览器、换站点地址或清除浏览器数据前，建议先点击右上角备份按钮，进入「备份与设置」导出 JSON 文件，再在新设备导入。隐私浏览模式、部分内置浏览器或存储限制可能影响保存；保存失败时网页会显示提示。

「已练题目」按实际提交过答案的不同题目数计算；「累计正确率」按全部提交次数计算。只看答案不会被算作已练题目。

## 题库来源与核对

来源：用户提供的《公开题库：旅游数字化产品设计与营销赛项.pdf》，共 83 页。

题目属于 2026 一带一路暨金砖国家技能发展与技术创新大赛第二届旅游数字化产品设计与营销赛项公开题库。题干、选项和标准答案照原 PDF 提取，保留各题型独立编号；仅整理换行与多余空格。原 PDF 未提供逐题解析，网页没有另行编造解析。原 PDF 一并附在 `assets/original-question-bank.pdf`。

已将全部 500 道题的题干、选项和答案使用两种 PDF 文本提取方式进行交叉核对，处理了 56 道跨页题目。原 PDF 中的个别措辞和标准答案按原样保留，不对内容另作事实修订。

题目反馈中的页码指 PDF 文件实际页序，包含封面；可能比页面底部印刷页码大 1。部分手机 PDF 阅读器不支持自动跳转页码，可以手动翻到标注页面。

## 常见问题

**部署后 404？**
确认 `index.html` 在所选发布目录根部，Pages 设置为 `main` 和 `/(root)`，并查看仓库 Actions 中的 Pages 发布是否成功。新部署完成前，网址可能暂时不可用。

**网页打开但没题目或没样式？**
通常是 `assets` 文件夹没有完整上传，或者目录层级不同。请保持压缩包里的相对路径关系。

**刷新后没有保留进度？**
检查是否换了浏览器、设备或站点地址，是否处于隐私模式，或浏览器是否清除了本地存储；可用 JSON 备份转移和恢复。

**修改代码后仍显示旧内容？**
部署成功后再强制刷新页面。此项目没有注册 Service Worker，不会主动锁定旧版本缓存。
